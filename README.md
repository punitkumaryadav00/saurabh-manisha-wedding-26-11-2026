# Saurabh & Manisha — Interactive Luxury Wedding Invitation

A bespoke, mobile-first luxury digital wedding invitation website built with Next.js 16, Tailwind CSS v4, and Framer Motion, featuring custom watercolor illustrations, bilingual English / हिंदी switching, an embossed wax-seal envelope reveal with golden sunburst animation, ambient synthesized string melody, live event countdown, rose-bud timeline, multi-venue interactive maps, dress code palette, complete family blessings card, and interactive RSVP with WhatsApp confirmation.
